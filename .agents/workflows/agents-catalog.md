# Agents Catalog

## Agents Fixos do Núcleo
- Engineering Conductor Agent: coordena fases e execução.
- Context Governance Agent: protege contexto e precedência de artefatos.
- Living Documentation Agent: mantém documentação viva.
- TDD First Agent: garante testes antes de implementação funcional relevante.
- Quality Gate Agent: valida critérios objetivos de qualidade.

## Agents Especializados Criados no Dia 0
- Architecture Agent: valida arquitetura e fronteiras.
- Domain Modeling Agent: modela domínio e contratos.
- XP Pair Programmer Agent: implementa small releases guiadas por testes.
- Refactoring Agent: refatora preservando comportamento.

## Agents por Fase
- Dia 0: Architecture Agent, AI Jail Agent, Infrastructure DevOps Agent.
- Dia 1: Product Discovery Agent, Domain Modeling Agent, Architecture Agent, Frontend Architecture Agent, Database Architecture Agent.
- Dia 2: Domain Modeling Agent, QA Strategy Agent, Frontend Testing Agent.
- Dia 3: XP Pair Programmer Agent, Schema Design Agent, Integration Agent, UI Agent.
- Dia 4: XP Pair Programmer Agent, UI Agent, UX Agent, Frontend Architecture Agent, Integration Agent.
- Dia 5: Refactoring Agent, Design System Agent, Data Integrity Agent, Performance Agent sob demanda.
- Dia 6: Frontend Architecture Agent, UI Agent, UX Agent, Accessibility Agent, PWA Mobile Agent.
- Dia 7: Application Security Agent, Observability Agent, Infrastructure DevOps Agent, Deployment Agent.

## Regra de Ativação
Ativar o menor conjunto viável de agents. Agents sob demanda exigem evidência objetiva no contexto.
