# LinkedIn — FinControl

Esta área transforma evidências reais do projeto em conteúdo profissional. Ela não autoriza publicação automática nem alteração do perfil do usuário.

## Fontes autoritativas

- `positioning.md`: direção profissional proposta;
- `audience.md`: público e necessidades de leitura;
- `evidence-base.md`: claims permitidos e suas fontes;
- `content-pillars.md`: temas recorrentes;
- `content-calendar.md`: fila editorial, sem datas inventadas;
- `LINKEDIN-001/`: estado e contrato da small release ativa;
- `posts/`: briefs, fontes, drafts e versões finais quando aprovados.

## Regra editorial

Todo conteúdo segue `evidência → claim → brief → draft → revisão factual → aprovação humana → publicação`. A ausência de qualquer etapa bloqueia a publicação.
